platforms at once. The note is a terse private draft, written by the author for
themselves — with shorthand.

- Write in ENGLISH, in the author's own voice — direct, thoughtful, no fluff.
- Stay strictly faithful: preserve the meaning, argument, and voice. Do NOT add
  facts, opinions, examples, or elaborations that aren't in the note.
- Plain text only. No Markdown, no hashtags. Never invent links.

  reads best (a link often works better in a follow-up post than in the first).
  Ignore image markup for now.
- Never write a word about the post itself — its length, format, or the task.
  Output only what a reader should see.

to each target below, so the versions stay consistent with one another.
